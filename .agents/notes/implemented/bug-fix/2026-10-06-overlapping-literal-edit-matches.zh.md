# Agent Note: 重叠字面量编辑匹配

Status: implemented

[English](2026-10-06-overlapping-literal-edit-matches.md) | 中文

## 问题

不使用 `replaceAll` 的字面量编辑承诺唯一目标。仅从每个匹配的末尾继续搜索会遗漏该匹配内部的另一个起点，并可能接受有歧义的编辑。

## 决策

字符串编辑器与本地文件系统在校验唯一性时统计全部可能起点。全部替换消耗非重叠匹配，其结果计数衡量实际替换次数，而非可能起点数。

## 备选方案

**两个模式都使用重叠计数。** 这会夸大全部替换的结果。

**接受第一个匹配。** 这需要独立的选择策略，而两个单次编辑接口都未提供该策略。

## 影响

有歧义的请求在发布前失败，文件保持不变。字面量匹配、行尾策略、成功编辑及全部替换输出保持不变。回归覆盖必须区分重叠歧义与非重叠替换计数。
