# Agent Note: 桌面文件元数据字符串转义

Status: implemented

[English](2026-10-06-desktop-entry-metadata-escapes.md) | 中文

## 问题

Freedesktop 显示名与图标使用字符串转义，包括表示空格的 `\s`。字面值可能显示转义文本或导致图标查找失败。可执行命令具有独立的引用规则。

## 决策

共享桌面文件读取器使用五种标准字符串转义，对 `Name`、本地化 `Name` 键及 `Icon` 解码一次。`Exec`、`TryExec` 与其他字段保持字面值。两个应用目录使用相同的已解码元数据。

## 备选方案

**解码所有字段。** 这可能改变可执行命令的引用。

**重复解码。** 这会把字面转义反斜线后跟的 `s` 转换为空格。

**使用 Shell 或 JSON 反转义。** 这接受的语法与桌面文件规范不同。

## 影响

合法转义名称显示预期文本，转义图标名或路径进入正常图标查找。启动参数与注册验证保持不变。解析器、真实文件关联及 Host HTTP 图标测试覆盖共享读取器。
